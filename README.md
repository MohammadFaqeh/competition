# منصة المسابقة السنوية القرآنية

افتح `index.html` مباشرة في متصفح حديث. لا تحتاج المنصة إلى خادم أو اتصال بالإنترنت.

## قبل المسابقة

1. أنشئ دورة المسابقة ورمز الدخول عند التشغيل الأول.
2. أضف المتسابقين أو استورد `participants-template.csv` بعد تعبئته.
3. نزّل نسخة احتياطية تجريبية وتأكد من إمكانية استعادتها.
4. استخدم جهازاً واحداً بوصفه المصدر الرسمي للسحب، وخذ نسخة احتياطية دورية.

## قاعدة المواضع

- المصدر: Quran Foundation Content API v4.
- 6236 آية، 114 سورة، وترقيم صفحات مصحف المدينة.
- تُفحص سلامة البيانات عند كل تشغيل.
- يُولّد بنك المواضع محلياً وفق حدود السور وطول النص.
- اختيار الأجزاء والمواضع يستخدم Web Crypto مع تفضيل المواضع غير المستخدمة وتقليل التكرار، مع السماح بالتداخل عند الحاجة.
